### Tools

<div class="row">
{{< projentry name="DBackup" date="2021" link="https://github.com/drosocode/dbackup" imgid="dbackup" state="completed" >}}
A database backup solution. Supports MySQL/MariaDB, Postgres, Influx DB (v1) and MongoDB. Compresses the backups into a single zip on a regular basis (cron). Written in python and running in docker.
{{< /projentry >}}


{{< projentry name="NetBackup" date="2021" link="https://github.com/drosocode/netbackup" imgid="netbackup" state="completed" >}}
A network configuration backup solution. Supports SwitchOS, DLink Switches, OPNsens and OpenWRT. Saves the backups on a git repo on a regular basis (cron). Written in python and running in docker.
{{< /projentry >}}
</div>

<br/>

<div class="row">
{{< projentry name="IP Blocker" date="2021" link="https://github.com/drosocode/ipblocker" imgid="ipblocker" state="deprecated" >}}
Software to block IPs on OPNsense firewall based on a gelf stream from Graylog. Written in python.
{{< /projentry >}}

{{< projentry name="docker-bstreamer" date="2020" link="https://github.com/drosocode/docker-bstreamer" imgid="bstreamer" state="completed" >}}
Docker image used to stream a browser's video/audio over RTSP. Also includes a noVNC server and a proxy for puppeteer.
{{< /projentry >}}
</div>

<br/>

<div class="row">
{{< projentry name="Bookmarks" date="2023" link="https://github.com/drosocode/bookmarks" imgid="bookmarks" state="arch" >}}
Quick and dirty bookmarks manager written in Go + React supporting SSO (header auth), tags, and website backup (based on playwright).
{{< /projentry >}}

{{< projentry name="matrix-webhook" date="2022" link="https://github.com/drosocode/matrix-webhook" imgid="matrixwebhook" state="completed" >}}
